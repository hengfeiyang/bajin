# 八金官网

这是八金 iOS 记账应用的官方网站，托管在 GitHub Pages 上。

当前展示版本：`3.2.0`

## 网站结构

```
website/
├── index.html          # 首页
├── privacy.html        # 隐私政策页面
├── support.html        # 支持页面
├── styles.css          # 样式表
├── .nojekyll          # GitHub Pages 配置
└── README.md          # 本文档
```

## 技术栈

- 纯静态 HTML/CSS
- 少量原生 JavaScript 用于主题切换和交互
- 响应式设计，支持移动端和桌面端
- 无需构建工具
- 快速加载，SEO 友好

## 内容维护

`3.2.0` 首页突出预算成绩单分享：上月支出未超总预算时，可从上月统计保存或分享一张百分比卡片，不显示具体金额、账本明细或备注，无需订阅。官网介绍分享入口、图片隐私和使用价值。

`3.1.0` 完善消费统计：首页突出年度到月度的消费复盘，帮助页新增消费统计说明。以下功能属于免费版，不与 AI 订阅混淆：

- 年度月份入口：月度详情行或柱状图月份进入对应年月的月度统计，返回保留所选年份。
- 年度大额消费 Top 10：所选年份普通账本金额最高的 10 笔单笔支出，不足 10 笔时展示实际数量。
- 月度消费列表：默认金额从高到低，可切换为时间从新到旧，平铺展示，不按天分组。
- 统计只读：消费记录不提供详情或编辑入口，修改和删除仍从首页消费明细或账本明细进入。
- 统计范围：仅普通账本的支出，排除收入和结余账本记录。

`3.0.0` 增加无需订阅的本机 5 次 AI 免费体验，新老未订阅用户均可使用，App 与 Siri 共用额度，不限时、不按月重置。与 App Store 的订阅试用优惠分开描述；订阅价格和优惠资格以购买页面为准，不承诺统一的试用天数。

官网首页应与 App 当前功能保持一致。以下既有能力继续保留在功能介绍中：

- Siri 记账：通过 App Shortcuts 唤起八金，用语音输入消费内容
- Siri 消费分析：复用 App 内 AI 智能查询能力，支持自然语言分析问题
- AI 自然语言记账：App 内输入消费文本并自动解析
- 高级版权益：Siri 记账、AI 记账、AI 消费分析和预算提醒
- iOS 26 Liquid Glass：顶部操作、侧边栏、底部操作区和 AI 输入栏使用系统原生玻璃材质
- 系统兼容性：最低支持 iOS 18.0；Liquid Glass 在 iOS 26 及以上启用

预算管理文案需要同时说明：

- 分账预算：每个账本设置独立月预算
- 整体预算：所有普通账本共用一个本月总预算
- 整体预算模式下，新增账本不需要填写预算
- 月末结转会按当前预算模式处理
- 备份恢复：`.bajin` 备份包含账本、交易和预算设置，并兼容旧版备份
