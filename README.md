# 八金官网

这是八金 iOS 记账应用的官方网站，托管在 GitHub Pages 上。

当前展示版本：`1.5.0`

## 网站结构

```
website/
├── index.html          # 首页
├── privacy.html        # 隐私政策页面
├── support.html        # 支持页面
├── styles.css          # 样式表
├── .nojekyll          # GitHub Pages 配置
└── README.md          # 本文档
```

## 技术栈

- 纯静态 HTML/CSS
- 少量原生 JavaScript 用于主题切换和交互
- 响应式设计，支持移动端和桌面端
- 无需构建工具
- 快速加载，SEO 友好

## 内容维护

官网首页应与 App 当前功能保持一致。`1.5.0` 起，预算管理文案需要同时说明：

- 分账预算：每个账本设置独立月预算
- 整体预算：所有普通账本共用一个本月总预算
- 整体预算模式下，新增账本不需要填写预算
- 月末结转会按当前预算模式处理

## App Store 合规

本网站符合 App Store 的要求：

- ✅ 包含隐私政策页面
- ✅ 包含支持/联系方式页面
- ✅ 清晰说明应用功能
- ✅ 提供用户帮助文档
